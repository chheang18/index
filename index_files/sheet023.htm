Function Description:

Outright Profile file://192.168.60.200/cmdk_fs/03_Operators/OP/Match%20Creation%20Group/Outright%20Profile.pdf
Adjustment function description
Function Description:
1. Create Outright Profile set up:
1. Login Admin, after click League > New Profile, add new Outright Profile
2. On new Profile page, select League Type = Outright
3. After setting is completed, save it (League Type will be fixed after saving)
4. League > New League, select Outright when adding a new league. Profile menu below will change to the Outright setting interface, we can select the corresponding Outright profile by pulling down
2. Create Outright Event:
1. Add an Outright event. Please note that league we choose needs to be the one that has Outright profile set.
2. Match List can open Match, click drop-down menu 🅐 to filter Outright Only matches, and click Profile 🅑 to configure settings for a single Outright.
3. Point 🅑 can open a single Outright Match Profile for configuration.
